## 🎯 Overview

v4.3.2 adds two hardware capabilities — the **IR light board** and the **USB function** — and brings three image improvements: **motion-blur suppression**, **white-balance and color tuning**, and **wake-capture exposure**. The WiFi driver and firmware are upgraded with **auto reconnect** support. On the capture side it adds **stream parameters**, **runtime capture parameters** and **AI capture filtering**, and the **PIR configuration** is enhanced.

## ✨ Key New Features

| Feature | Summary |
|---------|---------|
| 🔦 IR light board | Auto-detected; day/night mode: always day / always night / scheduled window / auto by ambient light; IR intensity presets by subject distance |
| 🔌 USB function | Open the web UI at 192.168.10.10 over a USB cable; off by default, enabled from the web |
| 🏃 Motion-blur suppression | Caps the exposure time, visibly reducing motion smear |
| 🌗 White balance & color tuning | 3-point AWB enabled and re-calibrated for more accurate day colors |
| 🌅 Wake-capture exposure | Exposure readiness judged from scene luminance instead of a fixed frame wait |
| 🎥 Stream parameters | Resolution, bitrate and keyframe interval configurable on the web, applied immediately |
| 📷 Runtime capture parameters | Resolution (linked to the stream), skip frames, JPEG quality |
| 🤖 AI capture filtering | Only captures with an allowed target above the confidence threshold are kept or uploaded |
| 🎯 PIR enhancements | Device type, anti-jamming settings and quick presets |
| 📶 Auto reconnect | Automatically reconnects after an unexpected link loss until the link is back |
| 🕐 NTP time sync | NTP switch and server list configurable on the web |
| 📺 RTSP over TCP | RTSP clients can pull the stream over TCP, no UDP ports needed |

## 🐛 Important Fixes

- With a YuNet face-detection model the device misbehaved (rebooted or froze) and could not detect.
- After a model change the label text on detection boxes could render as colored speckle noise.
- Captures taken before the clock was ever synced were neither uploaded nor cleaned up.
- In instant-upload mode one capture could be uploaded twice, and an already-uploaded record could be marked as failed.
- System stability fixes.
- Operations stalled for about 30 s when the WiFi chip was unresponsive and never triggered recovery; now about 3 s with automatic recovery.
- On a weak cellular signal, PIN and operator commands timed out, were misreported as failed and re-sent.
- The physical capture button stopped responding on a poor network.
- The web preview stuttered periodically when the video frame rate was low.

## ⚠️ Upgrade Notes

> 📖 **Upgrading from a version below v4.3.1** (v2.x, v4.3.0, ...):
> read the **[OTA Update Guide](../v4.3.1/NE301_v4.3.1_OTA_Update_Guide.md)** first and follow it in order.
>
> **Upgrading from v4.3.1**: the partition table is unchanged — upgrade the APP, Web and WiFi firmware one by one from the web Firmware Upgrade page. FSBL, model and co-processor firmware need no upgrade.

1. **Upgrade the WiFi firmware to `2.17.5.42`** and the Web to `1.5.1.0`. After the APP upgrade the device reports a WiFi firmware version mismatch; complete the upgrade as prompted.
2. Do not close the browser page or power off during an upgrade. The WiFi firmware upgrade takes about 1–3 minutes.
3. **USB function is off by default**: enable it under System Settings → Device Configuration when needed.
4. **PIR "Disable during preview" now defaults to "No"** (was "Yes"). This applies to new devices and after a factory reset only; upgraded devices keep their stored setting.
5. **The "Grayscale mode" switch is removed**; on IR boards, day/night mode handles the color / black-and-white switching.
6. **Motion-blur suppression** increases noise and image size in dark scenes; enable it according to the scene.
