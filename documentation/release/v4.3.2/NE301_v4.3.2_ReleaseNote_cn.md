- **发版范围**: 自 v4.3.1（2026-09-18）以来的变更

| 组件 | 版本号 | 说明 |

| APP | **4.3.2.x** | 需升级 |

| FSBL / Model / WakeCore | 1.0.3.1 / 4.0.0.0 / 0.2.7.5 | 不变，无需升级 |

## 🎯 发布概览

v4.3.2 新增**红外灯板**与 **USB 功能**两项硬件能力，针对图像效果做了**运动模糊抑制、白平衡色彩调优、唤醒抓拍曝光**三项优化；同时完成 WiFi 驱动与固件升级并支持**断网重连**，抓拍侧新增**视频流参数、运行时抓拍参数、AI 抓拍过滤**，触发侧增强了 **PIR 配置**。

## ✨ 主要新功能

| 功能 | 说明 |
|------|------|
| 🔦 红外灯板支持 | 自动识别红外灯板；昼夜模式可选常白天 / 常黑夜 / 自定义时间段 / 根据亮度自动切换；红外灯强度支持按拍摄距离一键预设 |
| 🔌 USB 功能 | USB 连接电脑后通过 192.168.10.10 打开管理页面；默认关闭，可在网页开启 |
| 🏃 运动模糊抑制 | 限制曝光时间上限，运动物体拖影明显减小 |
| 🌗 白平衡与色彩调优 | 启用三点自动白平衡并重新标定，白天场景色彩更准确 |
| 🌅 唤醒抓拍曝光优化 | 按画面亮度判断曝光是否就绪，取代固定跳帧等待 |
| 🎥 视频流参数 | 网页可设置分辨率、码率、关键帧间隔，保存后立即生效 |
| 📷 运行时抓拍参数 | 分辨率（与视频流联动）、跳帧数、JPEG 质量 |
| 🤖 AI 抓拍过滤 | 只保存 / 上传识别到指定目标且置信度达标的抓拍 |
| 🎯 PIR 触发增强 | 新增设备类型、抗干扰配置、快捷预设 |
| 📶 断网重连 | 网络意外断开后自动重连，直至恢复 |
| 🕐 NTP 时间同步 | 网页可设置 NTP 开关与服务器列表 |
| 📺 RTSP over TCP | RTSP 拉流可走 TCP，无需开放 UDP 端口 |

## 🐛 重要修复

- 使用 YuNet 人脸检测模型时设备异常（重启或卡死），无法识别。
- 更换模型后，识别框上的标签文字可能显示为彩色噪点。
- 设备时间未同步期间拍到的图片不上传、不清理。
- 即时上传模式下同一条抓拍可能被上传两次，已上传成功的记录也可能被误标为失败。
- 系统稳定性修复。
- WiFi 芯片无响应时相关操作卡顿约 30 秒且不触发恢复，现缩短为约 3 秒并自动恢复。
- 蜂窝网络弱信号下 PIN、运营商等指令超时被误判失败并重发。
- 网络较差时按物理按键抓拍长时间无响应。
- 视频帧率较低时网页预览周期性卡顿。

## ⚠️ 升级说明

> 📖 **从低于 v4.3.1 的版本升级**（v2.x、v4.3.0 等）：
> 请先阅读 **[OTA 更新指南](../v4.3.1/NE301_v4.3.1_OTA_Update_Guide_cn.md)** 并按顺序操作。
>
> **从 v4.3.1 升级**：分区表没有变化，在 Web「固件升级」页分别升级 APP、Web 和 WiFi 固件即可，FSBL、模型、协处理器固件无需升级。

1. **WiFi 固件需升级到 `2.17.5.42`**，Web 需升级到 `1.5.1.0`。APP 升级后设备会提示 WiFi 固件版本不匹配，请按提示完成升级。
2. 升级过程中请勿关闭浏览器页面或断电；WiFi 固件升级约需 1–3 分钟。
3. **USB 功能默认关闭**：需要时在「系统设置 → 设备配置」中开启。
4. **PIR「预览期间禁用」默认值由「是」改为「否」**，仅对新设备和恢复出厂后的设备生效，升级上来的设备保持原设置不变。
5. **移除「灰度模式」开关**，红外灯板改用昼夜模式实现彩色 / 黑白切换。
6. **运动模糊抑制**开启后暗光场景噪点和图片体积会增加，请按实际场景决定是否开启。
