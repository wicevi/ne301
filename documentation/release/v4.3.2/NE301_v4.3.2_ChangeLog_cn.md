## ⚠️ 升级说明

> 📖 **从低于 v4.3.1 的版本升级**（v2.x、v4.3.0 等）：
> 请先阅读 **[OTA 更新指南](../v4.3.1/NE301_v4.3.1_OTA_Update_Guide_cn.md)** 并按顺序操作。
>
> **从 v4.3.1 升级**：分区表没有变化，在 Web「固件升级」页分别升级 APP、Web 和 WiFi 固件即可，FSBL、模型、协处理器固件无需升级。

1. **WiFi 固件需升级到 `2.17.5.42`**，Web 需升级到 `1.5.1.0`。APP 升级后设备会提示 WiFi 固件版本不匹配，请按提示完成 WiFi 固件升级。
2. **USB 功能默认关闭**：需要时在「系统设置 → 设备配置」中开启。
3. **PIR「预览期间禁用」默认值由「是」改为「否」**：仅对新设备和恢复出厂后的设备生效，升级上来的设备保持原设置不变。
4. **移除「灰度模式」开关**：红外灯板改用昼夜模式实现彩色 / 黑白切换。
5. **运动模糊抑制**开启后，暗光场景噪点和图片体积会增加，请按实际场景决定是否开启。

## ✨ 新功能（细化）

### 🔦 红外灯板支持

- 设备根据出厂硬件版本自动识别是否为红外灯板
- **昼夜模式**（图像管理页）：
  - 常白天（彩色）/ 常黑夜（红外夜视）：固定不动
  - 自定义时间段：时间段内为黑夜模式，时间段外为白天模式
  - 根据亮度自适应：按环境光实时判断，默认亮度 ≤ 20% 进入黑夜、≥ 80% 回到白天，两个阈值之间保持当前模式，避免频繁切换
- **红外灯**（灯光管理页）：强度可调；提供 4 米 / 5.5 米 / 6.5 米 / 9 米拍摄距离快捷预设，拍摄近处物体时降低强度避免过曝
- 红外夜视画面单独调校（曝光、对比度等）
- 休眠唤醒抓拍按已保存的昼夜模式决定滤光片与红外灯状态，不拖慢唤醒

### 🖼️ 图像优化

- **运动模糊抑制**（图像管理页，垂直翻转下方）
  - 开启后自动曝光时间上限为 10ms。实拍对比：3 米处正常步行的行人，拖影约从 40 像素降到 12 像素
  - 暗光场景以提高增益补偿，噪点会增加
  - 立即生效，重启后保持
- **休眠唤醒抓拍曝光优化**
  - 由「固定跳帧等待」改为按画面亮度判断曝光是否就绪
  - 光照稳定的场景下，相机启动后约 200ms 即可完成曝光准备并抓拍（该时间仅指相机启动后的曝光收敛，不含系统唤醒时间）
  - 场景明暗变化时自动延长等待，减少曝光不足或过度的抓拍
- **白平衡与色彩调优**
  - 启用三点自动白平衡（暖光 / 荧光 / 日光），并按实拍重新标定日光白点，白天场景色彩更准确
  - 室内、室外模式统一画质风格，仅测光区域不同

### 📷 抓拍与视频

- **视频流参数**（功能调试页）
  - 分辨率：子码流（AI 输入尺寸）/ 主码流（720P）/ 主码流（1080P）
  - 码率、关键帧间隔
  - 保存后立即生效，预览短暂中断后自动恢复
- **运行时抓拍参数**（功能调试页）
  - 分辨率（1080P / 720P / 4MP，与视频流联动）、跳帧数、JPEG 质量
  - 仅作用于设备运行期间的抓拍，不影响休眠唤醒抓拍
- **AI 抓拍过滤**（抓拍设置 → 推理配置）
  - 可设置是否启用过滤、置信度阈值、允许的结果标签
  - 不满足条件的抓拍不保存、不上传
- **批量下载**：存储管理的文件浏览、抓拍记录页均支持多选批量下载
- **文件保留选项**：已上传文件的保留时间由填写小时数改为档位选择（不保留 / 12 小时 / 1 天 / … / 3 年 / 永久保留 / 自定义）
- 待机或低功耗模式下，功能调试页提供「休眠唤醒抓拍参数」快捷入口，点击直达抓拍设置的对应位置

### 🎯 触发

- **设备类型**：PIR（人体红外，可调灵敏度与抗干扰）/ IO（电平信号，仅选择触发边沿）
- **抗干扰配置**：在设定时间内检测到足够次数的有效信号才触发，减少偶发干扰引起的误触发
- **快捷预设**：室内标准 / 室外抗干扰 / 极速抓拍 / 省电防刷屏，点击自动填入配置
- **灵敏度**：改为 1–100 标尺（数值越大越灵敏），并显示灵敏度档位和理论探测距离；已有配置自动兼容

### 📶 网络与时间

- **WiFi 升级**：驱动升级到 WiseConnect 4.2.0，配套固件 `2.17.5.42`
- **断网重连**：WiFi 掉线、路由器重启、POE 线路断开、蜂窝网络掉线等意外断开后自动重连，直至恢复；手动关闭的网络不会自动重连
- **WiFi 异常恢复优化**：热点与客户端各自独立恢复，单侧故障不再影响另一侧
- **USB 功能**（系统设置 → 设备配置）
  - 开关：关闭时设备完全不初始化 USB 以降低功耗，默认关闭
  - IP 模式：跟随热点（默认，与热点共用 192.168.10.10）/ 自定义
- **NTP 时间同步**（设备配置页）：开关 + 服务器列表（最多 4 个，支持域名或 IPv4 地址）
- **RTSP over TCP**：拉流客户端可选择 TCP 方式，视频数据与 RTSP 走同一连接
- 「设备密码管理」页签更名为「设备配置」，集中管理密码、NTP、USB

### 🤖 AI 与数据上报

- 调试页上传模型后即时生效更可靠：更换不同输入尺寸的模型会自动适配；加载失败时回滚到原状态并提示原因
- 目标检测框的标签新增置信度显示
- AI 结果遥测支持批量上报，减少消息条数（通过配置文件或接口设置）
- 人体关键点支持亚像素细化，关键点不再跳变（可选，需模型参数开启）

## 🔌 Web API 变化（供平台对接参考）

接口总数 176 → 187，新增：

| 方法 | 路径 | 用途 |
|------|------|------|
| `GET` / `POST` | `/api/v1/device/stream/config` | 视频流参数 |
| `GET` | `/api/v1/device/usb` | USB 运行状态 |
| `POST` | `/api/v1/device/usb/config` | USB 开关与 IP 模式 |
| `GET` / `POST` | `/api/v1/device/day-night/config` | 昼夜模式配置 |
| `GET` | `/api/v1/device/day-night/status` | 昼夜模式状态 |
| `GET` / `POST` | `/api/v1/system/ntp/config` | NTP 配置 |
| `POST` | `/api/v1/work-mode/timer-trigger` | 定时触发参数单独更新 |
| `POST` | `/api/v1/work-mode/remote-trigger` | 远程触发参数单独更新 |

已有接口的行为变化：

- MQTT 配置接口（`/api/v1/apps/mqtt/config`）：只传证书内容、不带文件路径时，证书现在会保存到设备并在重启后保留（此前仅保存在内存中）

完整的请求、响应与错误码说明见 [NE301 v4.3.2 HTTP API 参考](./NE301_v4.3.2_HTTP_API_cn.md)。
